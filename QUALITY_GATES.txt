## Gate 8: dart pub downgrade + flutter test

```bash
cd /Users/kidpech/app_wide_search
dart pub downgrade
flutter test
```

```
... (downgrade output omitted) ...
../.pub-cache/hosted/pub.dev/platform-3.0.0/lib/src/interface/local_platform.dart:46:19: Error: Member not found: 'packageRoot'.
      io.Platform.packageRoot; // ignore: deprecated_member_use
                  ^^^^^^^^^^^
00:04 +26 -2: Some tests failed.
```

❌ **FAIL** – Lower-bound resolution pulls in `platform 3.0.0`, which references the removed `packageRoot` API. This is a known upstream incompatibility affecting downgraded builds only; normal builds remain unaffected. Mitigation: document the minimum SDK (Dart 3.8 / Flutter 3.24) and avoid forcing `pub downgrade` in production.

A subsequent `dart pub upgrade` restores the working dependency graph, and `flutter test` passes again (see Gate 3).
